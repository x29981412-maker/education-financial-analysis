# 教育企业财务数据核验与现金流分析

选取新东方2023—2025财年的公开年报数据，研究财务报表中的基本勾稽关系，以及营业收入、利润和经营现金流的变化。本项目为三人小组研究，我负责数据整理与分析。

**[查看研究报告](paper/main.pdf)** · [报告文字版](paper/report.md) · [原始数据及页码](data/financials.csv) · [计算结果](results/indicators.csv)

## 研究内容

| 问题 | 处理方法 | 输出 |
| --- | --- | --- |
| 不同报表中的数据口径是否一致 | 统一财年、币种、合并范围与现金定义 | 数据表、原始科目和页码 |
| 所选财务数据是否满足基本勾稽关系 | 复算收入、利润、资产权益及现金滚动关系 | 22项检查记录 |
| 利润增长为何与现金流变化不同 | 比较同比、现金流与净利润之比，并拆分现金流变动 | 指标表、变动分解和分析报告 |

## 个人分工

- **数据整理：** 从官方年报整理28个指标、76个已披露观测值，保留原始英文科目、币种、财年及PDF页码。
- **口径核验：** 区分合并净利润与归母净利润，统一现金及受限现金口径；缺失的2023年资产负债表数据留空。
- **计算分析：** 复算22项勾稽关系，计算同比和财务比率，整理经营现金流变化与留学咨询业务收入的分析依据。

## 结果摘要

金额单位：百万美元。财年截至当年5月31日。

| 指标 | 2023财年 | 2024财年 | 2025财年 |
| --- | ---: | ---: | ---: |
| 营业收入 | 2,997.760 | 4,313.586 | 4,900.262 |
| 合并净利润 | 235.363 | 325.218 | 375.833 |
| 经营活动现金流量净额 | 971.008 | 1,122.643 | 896.592 |
| 经营现金流／合并净利润 | 4.13 | 3.45 | 2.39 |
| 留学咨询服务收入 | 354.764 | 439.744 | 516.367 |

2025财年营业收入和合并净利润分别同比增长13.60%和15.56%，经营现金流同比下降20.14%。现金流与利润的变化方向不同，需要结合递延收入及其他调整分析。

所选数据的22项基本勾稽检查差额均为零。现金流指标采用集团合并口径，覆盖教育课程、留学咨询和直播电商等业务；留学咨询服务单列收入及其占比。

## 数据来源

主来源为[港交所披露的新东方2025年报](https://www1.hkexnews.hk/listedco/listconews/sehk/2025/0925/2025092501682.pdf)。财务报表见PDF第187—197页，分部收入见第128页。另通过[公司投资者关系网站](https://investor.neworiental.org/financial-information/annual-reports)回查同一发行人的披露资料。

原始单位为千美元，分析表中的百万美元由原值除以1000得到。28个指标、76个观测值已使用`verify_source.py`逐行回查原PDF，结果见[来源核对记录](results/source_verification.csv)。来源链接、原文件校验值及口径说明见[data/sources.json](data/sources.json)。

## 文件与复算

```text
data/financials.csv              原始财务数据、英文科目和页码
data/sources.json                官方来源与口径
analysis.py                     指标计算与勾稽核验
results/                        指标、检查与现金流变动分解
paper/main.pdf                  小组研究报告
```

核心分析只使用Python标准库，在仓库根目录运行：

```bash
python analysis.py
```

生成PDF或核对原年报时，安装以下依赖：

```bash
python -m pip install -r requirements.txt
python report.py
python verify_source.py 下载的原年报.pdf
```

研究基于公开披露资料，范围为所选财务指标的口径核验、基本勾稽关系与趋势分析。
