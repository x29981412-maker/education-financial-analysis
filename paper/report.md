# 教育企业财务数据核验与现金流分析

以新东方2023—2025财年为例

## 1. 研究问题与个人工作

本研究以新东方教育科技集团2023—2025财年为例，核对公开财务数据的基本关系，并比较利润增长与经营现金流变化。研究采用三人小组形式，我负责数据整理与分析。

我的工作包括从原年报整理28个指标、76个已披露观测值，记录原始科目和页码，统一币种、财年与合并口径；在此基础上复算财务指标和勾稽关系，并整理现金流变化的分析依据。

数据来源为港交所披露的新东方2025年报。原始金额单位为千美元，财年截至每年5月31日。所选资产负债表只列2024、2025年，2023年相应数据留空。研究区间固定为2023—2025财年。

## 2. 数据口径与勾稽核验

录入时保留原表负数符号，费用和现金流出均按原表记录。利润采用合并净利润，与现金流量表起点一致；现金采用现金、现金等价物和受限现金合计，不能只取资产负债表中的现金等价物。

共进行22项基本勾稽检查，22项差额为零。检查包括收入加总、营业利润关系、净利润跨表一致性、现金流组成、现金滚动、资产负债权益关系与受限现金衔接。结果支持所选数据在这些关系上的算术一致性。

分部收入取自年报经营回顾表，与合并财务报表分开标识。集团业务还包括教育课程和直播电商，集团现金流不能直接当作留学咨询业务现金流。合计关系一致也不能代替交易层面的核实或审计意见。

## 3. 经营现金流与利润的变化

2025财年营业收入同比增长13.60%，合并净利润同比增长15.56%，经营活动现金流量净额则同比变化-20.14%。利润和经营现金流在该年度表现出不同方向。

经营现金流与合并净利润之比分别为4.13、3.45、2.39。这一比值描述两个已披露项目的关系，其变化需要结合预收学费、费用结算和非现金调整解释。

将2024至2025年的经营现金流差额分解：合并净利润增加50,615千美元，递延收入对现金流调整的贡献减少304,373千美元，其余调整合计增加27,707千美元，三项相加对应经营现金流减少226,051千美元。其余调整是差额汇总项，不是一项单独披露的现金流科目。

| 2024至2025财年变动 | 千美元 |
| --- | --- |
| 合并净利润变动 | +50,615 |
| 递延收入现金流调整变动 | -304,373 |
| 其他调整合计变动（差额计算） | +27,707 |
| 经营现金流总变动 | -226,051 |

## 4. 留学业务与研究结论

留学咨询服务收入由2023财年的354.764百万美元增至2025财年的516.367百万美元。2025财年约占集团收入的10.54%。这可以用于了解留学服务板块规模，但不能据此分摊集团经营现金流或推断某家留学机构的收款情况。

研究中最需要注意的是口径：财年与自然年不同，合并净利润与归母净利润不同，现金流量表期末现金也包含受限现金。这些差异会影响比率与勾稽结果，必须先统一口径再做解释。

我的主要贡献是把年报中的分散数据整理成可追溯的数据表，复算勾稽与指标，并将现金流变动拆解到可回查的科目。研究结论限于公开年报中的所选数据和基本财务关系。未接触企业内部账簿、银行流水或审计底稿。
